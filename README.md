## 📌 Principles I follow

- Business logic belongs in the domain layer, not in controllers
- Repositories should own data access, not business decisions
- APIs should fail clearly, not silently
- Caching must be deliberate, measurable, and invalidatable
- Background jobs should reduce operational load, not hide broken flows
- Desktop UI logic should stay separated from business logic
- Simpler architecture is better until complexity becomes justified

---

## 🧭 How I think about software engineering

Good software is not just code that works.

It should be predictable under load, understandable for the next developer, observable in production, and aligned with the business process it represents.
